An AI-enabled data pipeline.

Agents propose. Code executes. Humans decide.

Every dataset in the stack is made of four things: the physical tables that hold the bytes, the logical rules that shape them, the agents that propose work against them, and the context that says what any of it means. Six data products, source to decision, each built from those four.

Operating Rule

Agents propose. Code executes. Humans decide.

01

Agents propose

Models triage quality failures, draft column mappings, propose entity matches, explain a variance, and write the first version of a transformation. They produce reviewable diffs and evidence, never silent writes to production.

02

Code executes

Every number that reaches a dashboard is produced by versioned, tested, deterministic transformation. Same input, same output, every run. An accepted suggestion becomes code and is held to the same bar.

03

Humans decide

Metric definitions, contract changes, match thresholds, access, and retention are approvals, not automations. The stack's job is to make the decision fast, evidenced, and reversible.
